# Healthcare ERP Backend — v1.0.3 Changelog

**Release Date**: August 27, 2026  
**Status**: Stable Release  
**OpenAPI Specification Version**: 1.0.3

---

## Summary of Changes

Version **v1.0.3** introduces foundational API infrastructure, robust request/response pipelines, centralized error and 404 handling, request correlation ID tracing, structured logging, a standardized pagination/sorting/searching engine, and the initial React Vite backend monitoring dashboard.

---

## Detailed Changelog

### 1. API Root & Versioning Strategy
- **Root API Discovery**: Built `GET /` returning server health, environment mode, active version, documentation links, and version discovery map.
- **URI Versioning Aggregator**: Created `GET /api/v1` exposing all domain routes and metadata for API v1.
- **Central Route Registration**: Implemented `src/routes/index.ts` with structured `registerRoutes(app)` pipeline aggregating root, health, telemetry, docs, and domain routes.
- **API Drift & Breaking Change Detector**: Created `scripts/check-api-drift.ts` (`bun run check:api-drift`) to analyze OpenAPI specifications and prevent accidental contract breakage.
- **Versioning Policy Documentation**: Created `docs/API_VERSIONING.md` detailing the URI versioning lifecycle, deprecation notices, and v2 decision matrix.

### 2. Request Validation & Response Formatting
- **Zod Validation Middlewares**: Implemented `validateBody`, `validateQuery`, and `validateParam` in `src/middlewares/validate.middleware.ts`.
- **Field-Level Error Mapping**: Formatted Zod schema violations into clean, structured `FieldErrorDetail[]` items (`field`, `message`, `code`).
- **Standardized Response Envelopes**: Built `sendSuccess`, `sendCreated`, `sendPaginated`, `sendNoContent`, and `sendError` in `src/shared/utils/response.util.ts`.
- **Response Type Definitions**: Established `ApiSuccessResponse<T>`, `ApiPaginatedResponse<T>`, `ApiErrorResponse`, and `FieldErrorDetail` in `src/shared/types/response.type.ts`.

### 3. Centralized Error Handling & 404 Handler
- **Domain Exception Hierarchy**: Created `AppException`, `ValidationException`, `NotFoundException`, `ConflictException`, `BadRequestException`, `UnauthorizedException`, `ForbiddenException`, and `UnprocessableEntityException` in `src/shared/exceptions/app.exception.ts`.
- **Centralized Error Middleware**: Global `errorHandler` catches custom `AppException`s, `ZodError`s, Prisma database constraint violations (`P2002`, `P2025`, `P2003`), and uncaught exceptions.
- **Structured 404 Handler**: `notFoundHandler` returns a standardized 404 `RESOURCE_NOT_FOUND` error envelope containing `path`, `timestamp`, and `requestId`.

### 4. Request Correlation IDs & Structured Logging
- **Request Correlation Middleware**: Created `src/middlewares/request-id.middleware.ts` generating/preserving `X-Request-ID` and `X-Correlation-ID` headers.
- **Distributed Trace Injection**: Automatically stamped `requestId` into Hono context, response headers, and all success/error JSON response envelopes.
- **High-Precision Request Logger**: Created `src/middlewares/logger.middleware.ts` measuring request processing latency with `performance.now()` and outputting structured logs with correlation IDs.

### 5. Pagination, Filtering, Sorting & Searching
- **Shared Query Types & Schemas**: Created `baseQuerySchema`, `PaginationMeta` (`page`, `limit`, `total`, `totalPages`, `hasNextPage`, `hasPreviousPage`), and `SortOrder` in `src/shared/types/pagination.type.ts`.
- **Query Parser Utilities**: Implemented `parsePagination`, `parseSorting`, `parseSearch`, `parseDateRange`, and `buildPaginationMeta` in `src/shared/utils/query.util.ts`.
- **Domain Integration**: Updated `Users` and `Patients` repositories and services to support multi-column searching, field-level whitelisted sorting, and date ranges.
- **Conventions Specification**: Documented full query standards and pagination envelope rules in `docs/CONVENTIONS.md`.

### 6. Backend Monitoring Dashboard (React + Vite)
- **Real-Time Telemetry Endpoint**: Created `GET /api/v1/telemetry` reporting RSS and Heap memory, process uptime, DB query latency, and entity counts.
- **React 19 + Vite Dashboard**: Built `dashboard/` SPA with Lucide React icons, real-time Canvas latency sparklines, Users/Patients domain explorers, and API workbench.
- **Integration**: Added `bun run dev:dashboard` and `bun run build:dashboard` scripts with build chaining.
